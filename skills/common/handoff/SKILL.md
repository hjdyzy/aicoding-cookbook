# 会话交接

整理下一位执行者需要的最少接续信息，保留事实、授权边界和下一步，避免复述整段对话。来源和本地适配记录见 [ORIGIN.md](ORIGIN.md)。

## 选择信息与位置

读取用户指定的接续目标和当前任务产物。已有规格、计划、任务 CSV、进度日志、ADR、提交或差异时，用路径或 URL 引用；只补充这些文件没有记录的关键上下文。项目采用 taskmaster 或其他跟踪方式时，引用其任务目录和权威状态文件。

尊重用户明确指定的输出位置。未指定时使用系统临时目录：Windows 取 TEMP 或 TMP，其他环境取 TMPDIR 或系统临时目录，Windows 上没有 /tmp。生成可识别且唯一的文件名，避免覆盖已有文档。临时目录不可用时明确报告原因，再选择已获授权的输出位置或询问缺失信息。

## 交接内容

- 用户目标、已确认范围及明确不做的事项。
- 项目根目录、分支、已知提交，以及哪些相关改动尚未提交；不要把无关工作区变更归于本任务。
- 已完成工作及其证据入口；已执行的验证、结果、未验证项和当前阻塞。
- 已有规格、任务状态和关键文件的绝对路径或稳定 URL。
- 已确认的关键决定、未解决问题、下一步具体操作及其所需条件。
- 用户已经授予和仍需取得的操作授权。
- 建议使用的相关技能及其用途。

按下一会话的目标裁剪内容。项目外部服务状态等无法核实的事实标注时间或证据局限，保留对下一步有影响的失败和风险，不把“曾经通过”写成“当前保证通过”。

## 脱敏与交付

移除凭据、认证头和不必要的个人信息；敏感值只写占位说明，不复制原文。保留环境变量名、错误码和必要路径以便定位，同时遵守用户的隐私要求。保存后读取自检：引用可定位、当前状态与任务产物一致，下一位能明确从哪里继续。向用户提供交接文件的绝对路径和简短说明。
